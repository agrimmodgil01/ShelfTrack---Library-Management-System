# LibraTrack Library Management System

 Browser-based library management system that demonstrates catalog management, member management, circulation workflows, overdue detection, fine calculation, search, filters, dashboard metrics, and persistent local state.

## Features

- Operational dashboard with inventory, loan, member, overdue, and fine metrics
- Book catalog with ISBN, category, shelf, copy count, availability, search, and filters
- Member records with type, contact details, loan limits, active loans, and fines
- Circulation workflow for issuing and returning books
- Automatic overdue status and fine calculation
- Demo data reset and localStorage persistence
- Responsive, polished UI built with HTML, CSS, and JavaScript
